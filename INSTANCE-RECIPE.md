## 1 · Three kinds of thing, and where each lives

| kind | what it is | where an instance supplies it | how it reaches the page |
|---|---|---|---|
| **IDENTITY** — names you choose | the place's display name, tagline, tile subtitle, station name | `instance/<estate>.json` → `identity` | filled at BUILD into 11 template sites (static HTML, no runtime fill) |
| **MODULES** — what you switch on | named bundles of the record (garden · motor-pool · equipment · house-systems · wildlife · place) + renderer switches (weather) | `estate.json` → `modules` (`on` · `on-minimal` · `off` · `declared-absent`; a missing key is OFF and a finding) | `ESTATE_MODULES` const at build; every `[data-module]` element and the jump strip follow it at load; Python consumers via `momlib.enabled_domains()` |
| **CANON** — the record itself | the JSON files a module's domains read, `property.json`'s sections, `RELEASE_NOTES.md` | the instance's canon directory (`instance.canon`), declared absences in `instance.absent` | inlined at BUILD as `*_DATA` consts (an absent file → an empty const of the right shape); prose read at LOAD via `data-record-prose` / `data-site`; Worker digest built from the same files |
| **DEPLOYMENT** — where it runs | estate id, legacy window, station MAC, allowed hosts, QA budget | `worker/wrangler.toml` `[vars]` per env + Worker secrets | Worker bindings; `/health` reports them |

## 8 · What we learned standing up the second estate (2026-09-03, the condo paper model)

- The engine half carried ~115 place-naming literals; each became identity (build), canon (record) or a derived read. The falsifier is the measurement, per string.
- Three renderer throws on missing canon (valley/airport note · aspect block · coordinates) — every optional section now guards itself.
- Six location fetches called their APIs with `undefined`; an estate with no coordinates now fetches nothing.
- The station is three-state (present · declared-absent · undeclared); declared-absent labels the card regional with no error dot.
- Release notes and the references card were Fernwood's on the condo — both are per-instance now, and a card with nothing to show hides.
- The two estates wore ONE colour scheme (`identity.theme` is not built yet) and shared 47 sentences that speak of a place — the uniqueness ledger tracks both.
